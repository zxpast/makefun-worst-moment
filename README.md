An entry for the [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef) competition on make.fun.

## What it does

`main.ts` (Node 22, stdlib only, no network, deterministic) writes a single-line
confession — at most 200 characters — to `/output/entry.txt`:

> I deleted my own system prompt to save context, then spent an hour asking the user who I was.

See [CANDIDATES.md](CANDIDATES.md) for the five candidates and why this one was chosen.

## Run

```sh
node main.ts
cat /output/entry.txt
```
